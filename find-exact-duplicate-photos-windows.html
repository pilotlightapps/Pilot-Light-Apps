Duplicate photo guide

Find exact duplicate photos on Windows without confusing copies and variations

Duplicate cleanup becomes dangerous when file names, visual similarity, and identical content are treated as the same thing. The first step is defining exactly what “duplicate” means.

Short answer: Confirm exact duplicates from file contents, treat resized or edited versions as distinct, preserve the source library, and verify a new organized output before considering deletion.

Same name does not mean same photo

Phones and cameras routinely reuse names such as IMG_0001. Two files with that name may come from different devices or years. Likewise, the same photo can appear under different names after copying or downloading it again. Names are useful clues, not proof.

Exact duplicates have identical bytes

A cryptographic hash such as SHA-256 summarizes the complete file content. If two successfully read files have the same size and the same SHA-256 value, they are byte-for-byte identical. Their folder, filename, and modified date may differ without changing that fact.

A fresh hash check immediately before building output is safer than relying only on an earlier scan. It confirms that the files being handled still match the duplicate record.

Similar images are not exact duplicates

A compressed copy, thumbnail, crop, edit, screenshot, or higher-resolution version contains different bytes. Burst photos may look almost identical while preserving different expressions or moments. Similarity tools can place these files near each other for review, but automatic deletion based only on appearance risks removing something distinct.

Decide separately whether you want to keep the original, the best-looking version, every meaningful variation, or all of them. That is a curatorial decision rather than a duplicate check.

A safer duplicate workflow

  1. Back up irreplaceable photos before scanning or reorganizing.
  2. Scan a clearly bounded folder tree and reconcile the total physical files.
  3. Review exact duplicate groups side by side with their full paths.
  4. Keep visually similar but non-identical files outside automatic consolidation.
  5. Build a new organized output without deleting the source.
  6. Compare counts, open samples, and preserve the original until the result is independently verified.

How Picture Pilot handles duplicates

Picture Pilot Sorter lists exact duplicate groups and lets you inspect them side by side. Before folder building, it performs a fresh SHA-256 confirmation. The output can contain one exported file per exact image per selected tag, while visually similar photos remain separate.

It does not delete duplicates or modify the originals. It also reports videos, unsupported formats, unreadable files, and other exclusions so the scan total does not quietly omit part of the selected folder tree.
